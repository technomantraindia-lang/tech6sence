4. STEP-BY-STEP IMPLEMENTATION INSTRUCTIONS (WHEN READY TO SETUP)
--------------------------------------------------------------------------------

STEP 1: Create Free Account on Resend
-------------------------------------
1. Go to https://resend.com and sign up.
2. Verify domain (tech6senseai.com) or add sender email info@tech6senseai.com.
3. Generate an API Key under Account Settings -> API Keys.

STEP 2: Add API Key to Environment File (.env)
----------------------------------------------
Create or update .env in project root:
  VITE_RESEND_API_KEY=re_123456789_your_api_key_here
  VITE_TARGET_EMAIL=info@tech6senseai.com

STEP 3: Install Required Helper Packages (Optional)
--------------------------------------------------
For client-side PDF generation:
  npm install html2pdf.js

STEP 4: Resend Email Dispatch Helper (Example React Code)
--------------------------------------------------------
Create src/utils/sendEmail.js:

```javascript
export async function sendFormEmail({ teamCategory, formName, clientData, fileAttachment }) {
  const subject = `${teamCategory} ${formName} - ${clientData.name || 'New Submission'}`;
  
  // HTML Template for Admin Notification
  const htmlContent = `
    <div style="font-family: Arial, sans-serif; background: #050112; color: #ffffff; padding: 30px; rounded: 16px;">
      <h2 style="color: #00A86B; border-bottom: 2px solid #1746D2; padding-bottom: 10px;">
        ${teamCategory} New Submission
      </h2>
      <p><strong>Form Name:</strong> ${formName}</p>
      <table style="width: 100%; color: #ffffff; border-collapse: collapse; margin-top: 15px;">
        ${Object.entries(clientData).map(([key, val]) => `
          <tr style="border-bottom: 1px solid #1e293b;">
            <td style="padding: 10px; font-weight: bold; color: #94a3b8; text-transform: capitalize;">${key}</td>
            <td style="padding: 10px;">${val}</td>
          </tr>
        `).join('')}
      </table>
    </div>
  `;

  // Call Resend API Endpoint
  const response = await fetch('https://api.resend.com/emails', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${import.meta.env.VITE_RESEND_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      from: 'TECH6SENSE AI Forms <forms@tech6senseai.com>',
      to: ['info@tech6senseai.com'],
      subject: subject,
      html: htmlContent
    })
  });

  return response.ok;
}
```
